## Idea

Персональная цифровая система сопровождения одного человека на протяжении жизни: сохраняет непрерывность контекста, помогает организовывать информацию, задачи и решения и меняет свои возможности вместе с этапами жизни человека.

Ключевой принцип:

```text
AGENT ASSISTS
HUMAN DECIDES
```

## Why it is in the Agent Library

Это не готовый агент и не сертифицированный компонент. Он зарегистрирован как **development candidate**, чтобы дальнейшая проработка шла через существующий FATHER Agent Zoo / agents library, а не в отдельном параллельном реестре.

## Lifecycle hypothesis

```text
birth / early childhood
→ childhood
→ education
→ adolescence
→ early adulthood
→ career / family / household
→ mature adulthood
→ retirement
→ late-life support
→ end-of-life / digital legacy handoff
```
