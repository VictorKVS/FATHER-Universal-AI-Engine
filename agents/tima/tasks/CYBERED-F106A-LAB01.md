# CYBERED-F106A-LAB01 — диагностика стенда виртуализации

**Исполнитель:** Тимофей (TIMA)  
**Режим:** READ ONLY → PLAN; без установки, удаления и переноса данных.

## Preflight
- [ ] Проверить CPU, RAM, GPU, свободное место, поддержку виртуализации
- [ ] Определить версии Windows, WSL2, Hyper-V, VirtualBox/VMware, Docker и Minikube
- [ ] Проверить текущие VM, volumes, виртуальные сети без изменения их состояния
- [ ] Выявить конфликты гипервизоров, недостаток места и риски для существующих проектов
- [ ] Создать ресурсный бюджет под Windows/Linux/Astra Linux учебной лаборатории
- [ ] Спроектировать изолированную сеть (без мостового подключения к рабочей LAN)
- [ ] Составить план резервного копирования, snapshots, восстановления и отката
- [ ] Согласовать исполняемые шаги отдельно
- [ ] Выполнить тесты только после подтверждения
- [ ] Сохранить evidence: конфигурации, логи, тесты, выводы

## Критерии приёмки
Никакие настройки рабочего хоста, диски, сети, учётные записи или существующие ВМ не менялись при диагностике. Предоставлен план с перечнем затронутых объектов и явными разрешениями на каждый этап.
