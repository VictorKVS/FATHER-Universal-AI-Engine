## Evidence and lifecycle
Statuses: backlog → draft → in review → approved → implemented → verified. Documentation alone is NOT evidence of implementation or compliance. Every verified control must reference a real test artifact, CI run or signed audit finding.

## Convention
Docs are numbered; ADRs use `docs/adr/ADR-0001-*.md`; diagrams are generated from versioned, machine-readable architecture definitions.
